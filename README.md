# scooter

Engenharia reversa do protocolo BLE do patinete elétrico **DNTOO B8D1**.

## Objetivo

Entender e documentar a comunicação Bluetooth entre o app oficial e a controladora do patinete,
para permitir monitoramento e controle por um app próprio.

## Status

- [x] Protocolo AT-A5 documentado
- [x] App web (PWA) com painel, mapa, histórico e fuzzer de bytes
- [ ] Documentação adicional de bytes, com apoio do fabricante da controladora (ZB-M1)
- [ ] Código e documentação publicados neste repositório

## Aviso

Projeto pessoal e experimental. Alterar parâmetros da controladora pode danificar o patinete ou anular a garantia — use por sua conta e risco.
